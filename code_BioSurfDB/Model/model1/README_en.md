# BioSurfDB Molecular Fingerprinting — Task 1: General Biological Function Annotation Status Classification

## Overview

This task uses Morgan fingerprints (radius=2, nBits=1024) and machine learning models (Random Forest, XGBoost) to perform **binary classification of a compound's general biological function annotation status** (`biological_activity`, YES / NO).

- **Positive samples (pos)**: `biological_pos.xlsx`, where the `biological_activity` column is `YES`.
- **Comparison samples (comp)**: `biological_comp.xlsx`, where the `biological_activity` column is `NO`, serving as the comparison (second) class.

> Note: `biological_comp` is a *comparison / reference* set, not an absolute "inactive" set — it is simply the contrast population for the binary task. The training label always comes from the `biological_activity` column.

A 5-fold stratified cross-validation is performed, with ROC curves, classification metrics (Accuracy, Precision, Recall, F1, ROC-AUC, MCC, Balanced Accuracy), and Morgan bit importance analysis generated.

## Data Preparation

The required input files `biological_pos.xlsx` and `biological_comp.xlsx` are already provided in the `input/` folder.

The input Excel must contain the columns produced by the upstream RDKit script (`../RDkit/deal_RDkit.py`). The pipeline reads 4 of them:

| Column | Description |
| --- | --- |
| `Database_ID` | Compound identifier |
| `SMILES_Parent_RDKit` | Desalted/uncharged canonical SMILES, used for fingerprint generation (the only fingerprint source column) |
| `biological_activity` | **Task 1 label** (YES/NO → 1/0) |
| `antimicrobial_activity` | **Task 2 label** (antimicrobial activity; unused by Task 1, kept for reference) |

> Label mapping rule (`map_label`): `YES`/`TRUE`/`1` → 1; everything else (including `NO`, empty, `NaN`) → 0.

## Running the Pipeline

All scripts locate the project root via `Path(__file__).resolve().parent.parent` and use absolute paths, so they can run from anywhere.

```bash
conda activate surfmodel
cd Model/model1/scripts
```

1. Generate Fingerprints

   ```bash
   python 01_generate_fingerprints.py
   ```

   Output: `input/fingerprints_biological/fingerprints_pos.csv`, `fingerprints_comp.csv`

2. 5-Fold Stratified Split

   ```bash
   python 02_cross_validation_5fold.py
   ```

   Output: `input/cv_folds_biological/fold_*_train.csv`, `fold_*_val.csv`

3. Train Random Forest

   ```bash
   python 03_train_random_forest.py
   ```

   Outputs: `output/biological/rf_cv_results.csv`, `rf_summary.csv`, `figures/rf_roc_curves.png`

4. Train XGBoost

   ```bash
   python 04_train_xgboost.py
   ```

   Outputs: `output/biological/xgb_cv_results.csv`, `xgb_summary.csv`, `figures/xgb_roc_curves.png`

5. Bit Importance Analysis

   ```bash
   python 05_bit_importance_analysis.py
   ```

   Outputs: figures and `bit_importance_summary.csv` under `output/bit_importance_biological/`

> Tip: If you previously ran the scripts under the old naming, delete any leftover `fingerprints_positive.csv` / `fingerprints_negative.csv` in `input/fingerprints_biological/` to avoid confusion with the newly generated `fingerprints_pos.csv` / `fingerprints_comp.csv`.

## Result Interpretation

- **CSV result files**: per-fold Accuracy, Precision, Recall, F1, ROC-AUC, MCC, Balanced Accuracy.
- **Summary files** (`*_summary.csv`): mean of each metric over the 5 folds.
- **ROC curves**: closer to the top-left indicates better performance.
- **Bit importance plots**: top Morgan bits that stably appear in at least 3 folds (based on permutation importance).

## Task 2 (Optional)

Script `05_bit_importance_analysis.py` also supports the antimicrobial-activity task: set `TASK = "antimicrobial"` at the top of the file. The label column automatically switches to `antimicrobial_activity` and it reads `input/cv_folds_antimicrobial/` (you must prepare the corresponding 5-fold splits separately). The main pipeline follows Task 1 (`biological`).

## Important Notes

- All scripts use absolute paths via `Path(__file__).resolve().parent.parent`; no manual `cd` to a specific directory is required.
- Fixed random seed (`RANDOM_STATE = 42`) for reproducibility.
- The fingerprint source column is consistently `SMILES_Parent_RDKit`.
- Fingerprint radius `RADIUS = 2`, size `NBITS = 1024`; Random Forest uses `class_weight="balanced"` to handle class imbalance.

## Troubleshooting

**Q: Missing openpyxl?**
A: It is included in `environment.yml` and `requirements.txt`; recreate/reinstall the environment.

**Q: RDKit installation fails?**
A: Install via conda (Tsinghua mirror is configured):

```bash
conda install -c https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/ rdkit
```

**Q: `KeyError` or missing column when running script 01?**
A: Verify the input Excel contains the `biological_activity` and `antimicrobial_activity` columns with exactly those names (case-sensitive).
